# Light Is For Everyone

LIFE is a Christian community application for discussion, publishing, lessons,
member dashboards, and moderation.

The application root is `life-app/`. There is no root package.json.
Run application commands from that directory.

Start with:

- [Application setup and operations](life-app/README.md)
- [Contribution workflow](life-app/CONTRIBUTING.md)
- [Repository agent instructions](AGENTS.md)
- [Application agent instructions](life-app/AGENTS.md)
- [Engineering history](life-app/Project_Overview.md)

The `clerk-nextjs/` folders are separate starter applications. They are not
the LIFE application root; their local instructions apply within those folders.
